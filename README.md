# mudlet-scripts

Набор Lua-скриптов для [Mudlet](https://www.mudlet.org/) — клиента для текстовых MUD. Скрипты написаны под русскоязычный MUD «Сфера Миров» и вставляются в профиль Mudlet как триггеры и скрипты (каждый файл содержит в шапке инструкцию по установке).

## Файлы

| Файл | Назначение |
|------|------------|
| [antibot.lua](antibot.lua) | Распознавание анти-бот проверок и автоматический ответ на них |
| [mapper.lua](mapper.lua) | Автоматическое построение карты по данным MSDP (`MudMapper`) |

## antibot.lua

Сервер периодически проверяет игроков на ботоводство: присылает набор бессмысленных фраз, на которые нужно ответить командой вида «молиться я не бот». Скрипт ловит такие проверки, фильтрует ложные срабатывания и отвечает автоматически.

Как работает:

1. **Триггер подтверждения** — по строке `Отлично! Вы прошли проверку на ботинг.` отправляет ответ, дублирует событие в OOC-канал и сбрасывает `antiBotLastSent`.
2. **Триггер подозрительной строки** — регулярное выражение `^[А-ЯЁ][а-яё]*(?:\s+[а-яё]+){5,15}\.\s*$` отсекает строки из 6–16 слов. Далее строка проверяется:
   - длина в реальных символах (`utf8.len`) должна быть от 30 до 75;
   - наличие «осмысленных» слов из списка `safeWords` — если слово найдено, строка считается обычным описанием и игнорируется;
   - дополнительно слова проверяются по основам и наборам окончаний (`verbEndsPresent`, `verbStemsPresent`, `nounEnds`, `participleEnds` и т. п.), что покрывает русскую морфологию без перечисления всех словоформ;
   - повторы отбрасываются через кэш `antiBotSeenLines` / `antiBotSeenLinesOrder` (ограничен `antiBotMaxCache`).
3. **Счётчик** — проверка считается настоящей, когда набралось `antiBotRequiredCount` (5) уникальных строк в окне `antiBotWindow` (20 секунд) и с прошлого ответа прошло больше `antiBotCooldown`.
4. **Реакция** — строка подсвечивается красным, выводится предупреждение, вызывается `alert(10)`, в группу уходят сообщения «Идет проверка…». Через случайные 2–5 секунд отправляется `очистить` и одна из случайных фраз (`молит я не бот` и варианты), результат дублируется в `cecho` и `demonnic.chat`.

Замечание: скрипт использует глобальные переменные `antiBotTimestamps`, `antiBotSeenLines`, `antiBotSeenLinesOrder`, `antiBotMaxCache`, `antiBotRequiredCount`, `antiBotWindow`, `antiBotCooldown`, `antiBotLastSent` — они должны быть заведены в профиле Mudlet (например, в отдельном скрипте-инициализаторе).

## mapper.lua

`MudMapper` — обёртка над `generic_mapper`, которая строит карту не по парсингу текста, а по данным MSDP: сервер сообщает VNUM текущей комнаты, её название, зону и список выходов.

Возможности:

- **Подписка на MSDP** — при активации протокола запрашивает `REPORT` для `ROOM`, `HEALTH`, `MANA`, `MOVEMENT`, `LEVEL`, `EXPERIENCE`, `EXPERIENCE_MAX`, `MONEY`.
- **Переход по VNUM** — если VNUM известен, происходит `sysManualLocationSetEvent`; если комнаты ещё нет и маппинг включён, она создаётся и ей назначаются имя, зона и координаты.
- **Синхронизация выходов** — выходы комнаты приводятся в соответствие с `msdp.ROOM.EXITS`: лишние удаляются, недостающие добавляются, для ещё не созданных комнат ставятся заглушки.
- **Связывание комнат** — по обратному выходу предыдущая и текущая комнаты связываются `setExit`, а координаты корректируются по направлению (`dir_offset`).
- **Двери** — состояние дверей (`open`/`closed`) обновляется из строки `[ Exits: ... ]` без пересоздания комнаты.
- **Тёмные комнаты** — по триггеру на «Здесь темно…» и «Вы последовали за кем-то.» позиция всё равно обновляется, так как MSDP отдаёт VNUM и выходы.
- **Русские направления** — `dir_map` понимает `север/юг/восток/запад/вверх/вниз` и их сокращения, а `MudMapper.init()` восстанавливает английские `lang_dirs` и дополняет `translate` русскими названиями направлений.
- **Прочее** — `MudMapper.goto_vnum(vnum)` для speedwalk в уже известную комнату и подробная отладка через `MudMapper.dbg()` (включая лог отправляемых команд по `sysDataSendRequest`).

Установка: три триггера (`Room Exits Catch`, `Vision Fail Trigger`) и скрипт `MudMapper` — точные паттерны и привязки перечислены в комментарии в начале файла.

## Требования

- Mudlet 4.x (используются `utf8`, `msdp`, `getEpoch`, `raiseEvent`).
- Пакет [`generic_mapper`](https://wiki.mudlet.org/w/Manual:Generic_Mapper) для `mapper.lua` (глобальный объект `map`).
- Пакет `demonnic.chat` для уведомлений в OOC (`antibot.lua`).
- Поддержка MSDP на стороне сервера MUD.
